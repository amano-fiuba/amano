# Amano

Aplicación web para dividir gastos compartidos entre un grupo de personas, inspirada en Splitwise.

> Proyecto universitario en desarrollo.

## Stack

- Frontend: React + Vite
- Backend: Java + Spring Boot
- Base de datos: PostgreSQL

Para configurar tu entorno y levantar el proyecto, seguí la guía [first-steps.md](first-steps.md).
